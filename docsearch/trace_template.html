Reading guide and legend
Two phases
Indexing (done once per drawing) turns the PDF into OCR lines, chunks, embeddings and fact rows. Answering (per question) searches them and writes the answer. The top strip shows this trace's real counts; each number jumps to its stage.
Stage chips
A dashed chip is an indexing stage; a solid chip is an answering stage. Click a chip, press ← / →, or Space to play.
Panel
Input and Output are the data entering and leaving the stage. How it works, Parameters and Why it matters explain the code. Time is the wall-clock time measured when this trace ran; stages that are not timed show none.
Score bars
Rank rows: the bar is the position in the list (full = first). RRF rows: the score relative to the top score. Reranker rows: the score relative to the lowest and highest candidate. Bars are not comparable across stages.
Novelty
keep: at least 25 % of the chunk's character bigrams are new versus the chunks already kept (the first chunk is always kept). drop: fewer than 25 % are new, so it mostly repeats kept text.
Fact rows
Fnnn ids name rows parsed by code from the OCR text; each row names its source chunk.
Citations
A '#' followed by a number in an answer is a citation mark. search.locate() finds these marks; benchjson strips them before grading.
Thinking text
chat() returns the thinking text, but the recorded result files do not save it, so the page does not show it.
Charts
Drawn from this trace's data: the page overlay (each layer can be hidden), rank movement across the lists, the reranker score strip, prompt composition in characters, the measured stage timeline, and the answer comparison (numbers the reference also states are highlighted). Times are wall-clock milliseconds rounded to 0.1; "< 0.1 ms" means the step is plain string work.
